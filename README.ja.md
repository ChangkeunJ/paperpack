# paperpack

一連の質問に答えると、計算済みの数字が、その一つひとつの出典とともに返ってきます。
すべてブラウザ内で動作します。

https://paperpack-7v7.pages.dev/ でそのまま使え、インストールは不要です。入力した内容が
タブの外に出ることはありません。ホスト版でも、ご自身で動かした場合でも同じです。

![記入済みのワーキングホリデー税金パック](docs/screenshot.png)

最初のパックは、オーストラリアのワーキングホリデーメーカー税を計算します。417ビザまたは
462ビザの保有者は常時約21万1,000人おり、その大半は非課税枠なしで最初の1ドルから課税され、
さらに多くの人が、ワーキングホリデー雇用主として登録していない雇用主によって余分に
源泉徴収されています。そのお金は、申告して初めて戻ってきます。

出国時スーパーアニュエーション支払（DASP）も計算します。大半のバックパッカーにとって、
2つの金額のうち大きいのはこちらで、最も重く課税されるのもこちらです。

## できること

- 2025-26年度および2026-27年度のワーキングホリデー所得にかかる税金を計算します
- すでに源泉徴収された金額と、その差額を表示します
- 国籍によって結果が変わる箇所では警告を表示します。実際に変わるのは、8つの条約国と
  11の相互医療協定国です
- 条約国の居住者については*Addy*比較を実行します。ワーキングホリデーメーカーとして、
  またオーストラリア国籍の居住者としての両方で税額を算定して両方を表示し、安いほうを
  適用します。条約が実際に与えてくれるのはこれです
- DASP請求で税引後に手元に残る金額を計算します。ワーキングホリデー税率が適用される
  場合はその税率で、適用されない場合は通常の一時滞在者税率で計算します
- すべての数字を、その出典となるATOのページと、そのページを確認した日付とともに
  表示します
- 英語、韓国語、簡体字・繁体字の中国語、日本語、ベトナム語、フランス語、スペイン語に
  対応しています

## しないこと

- 何も申告しません。申告はmyTaxを通じて、ご自身の手で行います。
- 居住者方式が有利になると決めつけません。条約が与えるのは居住者税率ではなく、
  2つの算定のうち低いほうであり、両方が画面に表示されます。
- オーストラリア国外で得た所得は扱いません。その所得は比較の片側には算入され、
  もう片側には算入されないため、黙って間違えるのではなく、その旨を明示します。
- ATOがその年度のメディケア税の基準額を公表するまでは、居住者の2026-27年度の税額を
  推定しません。推測で答えるより、その年度を断るほうがましだからです。
- 読んでいない控除ルールはモデル化しません。2026-27年度からは300ドルまでの領収書
  不要の扱いが廃止され、居住者に限り1,000ドルの標準控除に置き換わるため、2つの年度は
  意図的に異なる動きをします。
- DASPの税率をビザだけで決めません。417または462の保有は判定の半分にすぎず、
  支払いにその保有期間中に積み立てられたスーパーアニュエーションが含まれている必要が
  あり、含まれている場合は支払額全体に高いほうの税率が適用されます。
- これは税務代理サービスではなく、ここにある内容はいずれも税務アドバイスではありません。
  公表されている税率を、入力された数字に当てはめるだけです。ご自身で確認し、信頼できる
  アドバイスが必要な場合は登録税務代理人にご相談ください。[docs/legal.md](docs/legal.md)を
  参照してください。

## 実行方法

```
pnpm install
pnpm build
npx http-server . -p 8080     # or any static server
```

その後、`/web/index.html` を開いてください。バックエンドはなく、設定するものも
ありません。入力した内容はタブの中にとどまります。

## ルールの保存方法

すべての規制上の数値は `packs/<pack>/rules/*.json` にあり、出典なしで出荷されるものは
一つもありません。

```json
"noTfnWithholdingRate": {
  "value": 0.45,
  "from": "2024-07-01",
  "source": "https://www.ato.gov.au/tax-rates-and-codes/schedule-15-tax-table-for-working-holiday-makers",
  "checked": "2026-08-18",
  "note": "45 per cent, not 47. The published 47 per cent applies to a resident payee; Schedule 15 sets a flat 45 per cent for working holiday makers with no residency test. The rate itself is long standing, but this URL is overwritten each 1 July and now serves the version effective 1 July 2026, so the start date recorded here rests on an archived copy of the previous version rather than on the live page."
}
```

`scripts/check.mjs` は、`value`、`from`、`source`、`checked` のいずれかを欠くルールを
拒否し、`rules` キーの外に置かれた規制データも拒否します。さらにテストスイートが、
各税率表の基準額がその下の表と一致することを検証します。打ち間違えた税率は、誰かが
誤った数字を目にする前に、こうして捕捉されます。

ページに発効日が公表されていない場合、`from` にはその値を最初に読み取った日を記録し、
ルールの `note` にその旨を記します。

オーストラリアの税率は7月1日に変わります。その前に出典を再確認してください。記録された
確認日が直近の7月1日より古くなると、月次のCIジョブが失敗し始めます。

## 言語の追加

`packs/au-whm-tax/i18n/en.json` をコピーし、キーはそのままに値を翻訳したうえで、
`web/index.html` にロケールを登録してください（`dicts` マップとボタン）。テストは
`i18n/` 内のすべてのファイルを取り込み、キーの欠落や空の値があれば失敗します。税務の
文言は翻訳で間違えやすいので、翻訳したものの隣には必ず出典リンクを表示したままに
してください。

## パックの追加

パックは、インタビュー（`interview.ts`）、1つ以上の計算（`calculate.ts`、`dasp.ts`）、
出典付きのルールデータ（`rules/*.json`）、文字列（`i18n/*.json`）で構成されます。
`src/` のエンジンは質問評価器と税率表計算器であり、オーストラリア固有の要素は一切
含まれません。
