# paperpack

질문에 답하면 계산된 금액이 나오고, 그 숫자 하나하나에 근거가 붙습니다. 전부
브라우저 안에서 돌아갑니다.

https://paperpack-7v7.pages.dev/ 에서 설치 없이 바로 쓸 수 있습니다. 입력한 내용은
탭 밖으로 나가지 않으며, 호스팅된 사본에서도 직접 띄운 사본에서와 똑같습니다.

![작성을 마친 워킹홀리데이 세금 팩](docs/screenshot.png)

첫 번째 팩은 호주 워킹홀리데이 메이커 세금을 계산합니다. 어느 시점에나 약 21만
1,000명이 417 또는 462 비자를 보유하고 있고, 그 대부분은 면세한도 없이 첫 1달러부터
과세되며, 워킹홀리데이 고용주로 등록하지 않은 고용주에게 과다 원천징수당하는 사람도
많습니다. 그 돈은 신고해야만 돌아옵니다.

출국 시 퇴직연금 지급액도 계산하는데, 대부분의 배낭여행자에게는 이쪽이 두 금액 중
더 크고 세금도 더 무겁게 붙는 쪽입니다.

## 하는 일

- 2025-26년도와 2026-27년도 워킹홀리데이 소득에 대한 세금을 계산합니다
- 이미 원천징수된 금액과 그 차액을 보여 줍니다
- 국적이 결과를 바꾸는 지점을 경고합니다. 8개 조약국과 11개 상호의료협정
  체결국이 여기에 해당합니다
- 조약국 거주자에 대해 *Addy* 비교를 수행합니다. 워킹홀리데이 메이커 기준과 호주
  국적 거주자 기준으로 세금을 각각 계산해 둘 다 보여 주고, 더 적은 쪽을
  적용합니다. 조약이 실제로 주는 것이 바로 그것입니다
- DASP 청구 후 세금을 떼고 남는 금액을 계산합니다. 워킹홀리데이 세율이 적용되는
  경우에는 그 세율로, 아닌 경우에는 일반 임시거주자 세율로 계산합니다
- 모든 숫자를 출처인 ATO 페이지, 그 페이지를 확인한 날짜와 함께 표시합니다
- 영어, 한국어, 중국어 간체와 번체, 일본어, 베트남어, 프랑스어, 스페인어를
  지원합니다

## 하지 않는 일

- 아무것도 대신 신고하지 않습니다. 신고는 myTax를 통해 본인이 직접 합니다.
- 거주자 기준이 이긴다고 가정하지 않습니다. 조약이 주는 것은 거주자 세율이 아니라
  두 가지 산정 중 낮은 쪽이며, 두 계산 모두 화면에 표시됩니다.
- 호주 밖에서 번 소득은 다루지 않습니다. 그 소득은 비교의 한쪽에는 들어가고 다른
  쪽에는 들어가지 않기 때문에, 조용히 틀린 답을 내는 대신 그렇다고 말해 줍니다.
- ATO가 해당 연도의 메디케어 부담금 기준선을 공표하기 전에는 거주자의 2026-27년도
  세금을 추정하지 않습니다. 한 해를 거절하는 편이 어림짐작보다 낫습니다.
- 읽어 보지 않은 공제 규정은 모델링하지 않습니다. 2026-27년도부터 300달러 무증빙
  공제가 폐지되고 거주자에 한해 1,000달러 표준공제가 그 자리를 대신하므로, 두
  연도가 다르게 동작하는 것은 의도된 것입니다.
- 비자만 보고 DASP 세율을 정하지 않습니다. 417 또는 462 보유는 요건의 절반일
  뿐이고, 지급액에 그 비자를 보유한 기간에 적립된 퇴직연금이 포함되어 있어야
  하며, 포함되어 있다면 워킹홀리데이 세율이 지급액 전체에 적용됩니다.
- 세무대리 서비스가 아니며 여기 있는 어떤 내용도 세무 자문이 아닙니다. 공개된
  세율을 입력한 숫자에 적용할 뿐입니다. 직접 확인하시고, 신뢰할 수 있는 자문이
  필요하면 등록 세무대리인에게 문의하세요. [docs/legal.md](docs/legal.md)를
  참고하세요.

## 실행

```
pnpm install
pnpm build
npx http-server . -p 8080     # or any static server
```

그다음 `/web/index.html`을 여세요. 백엔드도 없고 설정할 것도 없습니다. 입력한
내용은 탭 안에 머뭅니다.

## 규정 데이터의 저장 방식

모든 규정 수치는 `packs/<pack>/rules/*.json`에 들어 있고, 출처 없이는 하나도
배포되지 않습니다.

```json
"noTfnWithholdingRate": {
  "value": 0.45,
  "from": "2024-07-01",
  "source": "https://www.ato.gov.au/tax-rates-and-codes/schedule-15-tax-table-for-working-holiday-makers",
  "checked": "2026-08-18",
  "note": "45 per cent, not 47. The published 47 per cent applies to a resident payee; Schedule 15 sets a flat 45 per cent for working holiday makers with no residency test. The rate itself is long standing, but this URL is overwritten each 1 July and now serves the version effective 1 July 2026, so the start date recorded here rests on an archived copy of the previous version rather than on the live page."
}
```

`scripts/check.mjs`는 `value`, `from`, `source`, `checked` 중 하나라도 빠진 규칙과
`rules` 키 밖에 놓인 규정 데이터를 거부하고, 테스트 스위트는 각 세율 구간표의 기본
세액이 그 아래 구간들과 맞아떨어지는지 검증합니다. 잘못 입력된 세율은 이렇게 해서
누군가 틀린 숫자를 보기 전에 잡힙니다.

페이지가 발효일을 공표하지 않는 경우 `from`에는 그 값을 처음 읽은 날을 기록하고,
규칙의 note에 그 사실을 적습니다.

호주 세율은 7월 1일에 바뀝니다. 그전에 출처를 다시 확인하세요. 기록된 확인일이
가장 최근 7월 1일보다 뒤처지면 매월 도는 CI 작업이 실패하기 시작합니다.

## 언어 추가

`packs/au-whm-tax/i18n/en.json`을 복사해 값만 번역하고 키는 그대로 두세요. 그다음
`web/index.html`에 로케일을 등록합니다(`dicts` 맵과 버튼 하나). 테스트가 `i18n/`의
모든 파일을 읽어 들여 키가 빠졌거나 비어 있으면 실패합니다. 세금 문구는 번역에서 뜻이
틀어지기 쉬우니, 번역하는 내용 옆에 출처 링크를 계속 보이게 두세요.

## 팩 추가

팩은 인터뷰(`interview.ts`), 하나 이상의 계산(`calculate.ts`, `dasp.ts`), 출처가
붙은 규정 데이터(`rules/*.json`), 그리고 문자열(`i18n/*.json`)로 이루어집니다.
`src/`의 엔진은 질문 평가기와 세율 구간표 계산기이며, 호주에 특정된 부분은 하나도
없습니다.
